# MkDocs

Пример статического сайта на [MkDocs](https://www.mkdocs.org/), который можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Статический сайт — сборка Railpack |
| Одностраничное приложение (SPA) | выключено |
| Путь до директории проекта | `/` |
| Директория сборки | `/site` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | `mkdocs build` |
| Путь проверки состояния | `/` |

Порт указывать не нужно: статический сайт отдаётся на порту 80. Railpack видит
`requirements.txt` и ставит MkDocs, команда сборки кладёт готовые страницы в `site`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# виртуальное окружение и зависимости
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

# запуск в режиме разработки
mkdocs serve

# сборка для продакшн
mkdocs build
```

Нужен Python 3.9 или новее.
